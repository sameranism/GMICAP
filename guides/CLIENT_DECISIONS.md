# تصمیم‌های کارفرما / موارد باز

## تصمیم‌های پذیرفته‌شده
- ۹ بسته B01..B09 و ۲۹ پروژه P01..P29؛ یک داشبورد یکپارچه برای تیم.
- Python/FastAPI، PostgreSQL (سه محیط مرکزی/داخلی/خارجی)، Redis، React/TypeScript.
- ۵۰۰ تا ۵۰۰۰ خبر روزانه، حداکثر ۱۰ حساب انسانی با گذرواژه‌های اولیه تصادفی و مجزا.
- دو داشبورد مجزا برای مالک و مدیرمسئول؛ سه گزارش محرمانه صرفاً مدیرمسئول.
- AI Gateway دارای چند ارائه‌دهنده قابل تعویض.
- مقصدها: Telegram، Bale، Eitaa، Rubika، WhatsApp Business، سایر؛ در صورت وجود API رسمی و دسترسی مجاز.
- کنترل مستقل تولید گزارش عمومی، استودیو و انتشار؛ انتشار اصلی تا بعد از کنترل حقوق و کیفیت.
- هویت بصری بر اساس روزنامه اعتماد. انتخاب جدید UI: shadcn/ui، Tailwind v4، DTCG، Vazirmatn، Lucide، Tiptap، TanStack، React Aria در صورت نیاز. این تصمیم اخیر با Mantine قبلی مغایرت دارد و باید در ADR-002 رسماً جایگزین شود.

## تصمیم‌های باز که نباید حدس زده شوند
1. CMS نهایی و API معتبر آن.
2. فایل لوگو/رنگ‌های رسمی، مجوزها و فونت/دارایی‌های برند.
3. متن مصوب قواعد نشر و نتیجه بازبینی حقوقی ایران؛ سند فنی نمی‌تواند تطابق حقوقی را تضمین کند.
4. API رسمی و سطح دسترسی عملی هر مقصد و ارائه‌دهنده AI، سقف هزینه و کلیدهای امن.
5. دامنه‌ها/شبکه سرورها، روش Secrets و نوع S3 و سیاست نگهداری/بکاپ؛ تنظیمات staging باید بعداً تصویب شوند.
6. SLA و RPO/RTO و رویه اعلان/امضای انتشار محتواهای حساس.

برای موارد باز، Mock/Placeholder و STATUS=BLOCKED برای عملیات واقعی پذیرفته است. اجرای برنامه‌نویسی بر این اساس متوقف نمی‌شود.
