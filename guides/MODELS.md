# راهنمای انتخاب مدل و ابزار

| کد | محیط پیشنهادی | نقش | جایگزین مجاز |
|---|---|---|---|
| C | Codex در Cursor/محیط کدنویسی کاربر | معماری، دیتابیس، امنیت، API، پردازش حساس | مدل reasoning-capable واقعی موجود |
| G | Cursor Cloud Agent با Grok **موجود در حساب** | ماژول‌های مستقل و طولانی روی شاخه مجزا | Codex Cloud/Agent اگر مجاز و در دسترس |
| U | Cursor Local Agent با Grok موجود | UI، چیدمان، رفع جزئیات رابط | دیگر مدل کدنویسی موجود؛ تأیید بصری الزامی |
| R | Codex | ممیزی شواهد و PR | مدل موجود با توانایی تحلیل شواهد |

**قید مهم:** اعداد نسخه مدل‌ها، هزینه، سقف Cloud یا دسترسی شخصی کاربر بررسی نشده‌اند. مدل‌ها را از منوی واقعی Cursor انتخاب کنید. انتخاب مدل شرط پذیرش نیست. آزمون‌ها و شواهد هر تسک طبق ADR-012 ملاک‌اند.

**هزینه:** ابتدا هر بار یک task، پس از پذیرش Stage 0 حداکثر ۲–۳ عامل موازی با فایل‌های جدا. هیچ Cloud Agent را برای یک پوشه کامل با اختیار بازنویسی همگانی اجرا نکنید.

**ساختار شاخه:** `task/s02-001-b02` و یک PR فقط برای دامنه تسک؛ Gate مرحله پس از merge تسک‌های پایه و ثبت آزمون‌ها.
