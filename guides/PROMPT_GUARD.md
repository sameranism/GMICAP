# Prompt Guard — اصول مشترک تمام پرامپت‌ها

این بسته بر اساس مهارت Prompt Guard / «پرامپت‌ساز» برای پرامپت‌های قابل کپی طراحی شده است؛ خود مهارت اجرای کد یا کنترل خروجی مدل خارجی را تضمین نمی‌کند.

**پیش از اقدام:** منابع ذکرشده را از روی مخزن بخوان. واقعیت مستند، فرض، ابهام و نیازمند تأیید خارجی را جدا کن. اگر فایل لازم موجود نبود یا قرارداد قبلی با خواسته تسک تعارض داشت، با جزئیات `BLOCKED` گزارش کن و تغییر ناسازگار نده.

**حین اجرا:** فقط مسیرهای مجاز تسک را ویرایش کن؛ امکانات اضافی، بازنویسی‌های بی‌دلیل و ادغام کار چند پروژه ممنوع است. خروجی باید قرارداد داده و API، امنیت و حریم خصوصی، و آزمون‌های موجود را حفظ کند. به‌خصوص هیچ گزارش محرمانه‌ای نباید قابلیت انتشار داشته باشد.

**پایان:** فقط آزمون‌هایی را «موفق» اعلام کن که واقعاً اجرا کردی. فرمان، وضعیت خروجی، فایل‌های تغییرکرده، هشدارها، موارد انجام‌نشده و گام بازگشت را ارائه بده. اگر API رسمی/لوگو/CMS هنوز نامشخص است، جزئیات ساختگی ننویس.
