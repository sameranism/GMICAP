# اتاق خبر هوشمند اعتماد — بسته قراردادهای داده v1.0

این بسته همراه سند اجرایی Word ارائه شده است. همه فایل‌ها قرارداد پیشنهادی برای پیاده‌سازی آینده‌اند، نه خروجی سامانه عملیاتی.

## محتوا
- `schemas/*.schema.json` — JSON Schema Draft 2020-12 برای خروجی‌های مهم
- `examples/*.example.json` — نمونه داده ساختگی معتبر
- `project_contract_matrix.csv` — نقشه ۲۹ پروژه و خروجی/مصرف‌کننده
- `architecture.mmd` — نمودار Mermaid وابستگی‌ها
- `acceptance_tests.md` — حداقل آزمون‌های پذیرش

## نسخه‌ها
نسخه اصلی قرارداد `1.0` است. تغییر فیلد اختیاری با حفظ سازگاری مجاز؛ تغییر نام فیلد الزامی، تغییر معنا یا محدودکردن enum نیازمند نسخه اصلی جدید است. هر پیام و خروجی `schema_version` دارد. مصرف‌کننده در مواجهه با نسخه ناشناخته، رد و هشدار می‌دهد؛ حدس‌زدن ساختار ممنوع است.

## ذخیره و انتقال
برای نمونه‌سازی از JSON و JSONL استفاده کنید. در محیط عملیاتی، فایل‌های حجیم در object storage و ارجاع‌ها در پایگاه داده نگهداری شوند. انتقال بین پروژه‌ها با HTTPS احراز هویت‌شده یا صف پیام مجاز است، مشروط به اعتبارسنجی schema و حفظ correlation_id.

## قاعده محرمانگی
فقط `public_report` ممکن است پس از تأیید پروژه P11 وارد P22 شود. `private_report` هرگز در `publication_job` پشتیبانی نمی‌شود. API خروجی گزارش خصوصی فقط با نقش `editor_in_chief` مجاز است.

## قاعده قطع خروجی‌ها
تنظیمات `output_controls` مانع تولید گزارش عمومی (P18)، صوت و ویدئو (P20/P21)، و ارسال واقعی (P25) می‌شود. پردازش ورودی و آرشیو مستقل ادامه دارند. هنگام روشن‌کردن مجدد، کارهای معلق قدیمی خودکار ارسال نمی‌شوند؛ نیازمند ارزیابی مجدد هستند.

## اعتبارسنجی
`python validate_examples.py` را با کتابخانه `jsonschema` اجرا کنید.
