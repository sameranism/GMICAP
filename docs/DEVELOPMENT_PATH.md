## کد موجود و قابل اجرا در محیط محلی

- `backend/app/main.py`: ترکیب FastAPI، سلامت و خطای امن؛ مستندات API با فعال‌سازی صریح.
- `backend/app/demo_news.py`: دو خبر کاملاً ساختگی، فقط در حالت `ETEMAD_ENV=local` و `ETEMAD_DEMO_MODE=1`؛ اعتبارسنجی نخستین استفاده با قرارداد `normalized_news`.
- `backend/core/contracts.py`: خواندن قراردادهای JSON Schema نسخه ۱ و رد داده ناسازگار.
- `backend/core/output_switches.py`: تصمیم مستقل برای تحلیل عمومی، استودیو و انتشار؛ این تابع هنوز به ارسال واقعی متصل نیست.
- `backend/core/permissions.py`: تصمیم دسترسی با پیش‌فرض رد؛ حق گزارش ویژه فقط برای مدیرمسئول با grant صریح. هویت و مخزن grant هنوز متصل نیستند.
- `frontend/src/app/App.tsx`، `frontend/src/features/newsroom/NewsDesk.tsx`، `frontend/src/main.tsx`: میز خبر فارسی راست‌به‌چپ با فیلتر داخلی/خارجی، دریافت از API نمایشی، نمایش منبع و وضعیت خطا. اقدام انتشار ندارد.
- `frontend/package.json` و `frontend/package-lock.json`: نسخه‌های قفل‌شدهٔ وب.

برش نمایشی با ساخت وب، درخواست HTTP از مسیر Vite به API، و اعتبارسنجی نمونه‌ها بررسی شد. بررسی وابستگی‌های npm پس از اصلاح نسخه‌ها صفر آسیب‌پذیری گزارش کرد. این شواهد جای آزمون یکپارچهٔ محصول، مرور مستقل امنیت و Gate-00 را نمی‌گیرند.

## ترتیب توسعهٔ بعدی

1. **B01 / P28 و P02:** `backend/core/auth.py`، `audit.py`، `secrets.py`، `settings_service.py` و اتصال `permissions.py` به هویت و grant معتبر. مجوز باید در هر درخواست API و هر رکورد اعمال شود؛ مالک پیش‌فرض به گزارش ویژه دسترسی ندارد.
2. **B01 / داده و هماهنگی:** `backend/core/db.py`، `archive.py`، `sources_service.py`، `events.py`، `jobs.py`، `outbox.py`، `orchestrator.py`، سپس `backend/app/dependencies.py` و `api_router.py`. مهاجرت مرکزی `backend/migrations/central/001_baseline.py` باید نوشته و روی پایگاه دورریختنی بررسی شود؛ روی VPS اجرا نشود.
3. **B02 و B03:** دریافت داخلی و خارجی در پایگاه‌ها/صف‌های جدا، منبع دارای مجوز، ثبت اصل خبر و Bridge احراز هویت‌شدهٔ خارجی به مرکز. بدون تماس واقعی با منابع تا تأیید حق دسترسی.
4. **B04 و B05:** استانداردسازی، تشخیص تکرار، دسته‌بندی و جریان ویرایش/اعتبارسنجی با حفظ اصل خبر، نقل‌قول، منشأ و حق بازنشر.
5. **B06 تا B08:** تحلیل و گزارش‌ها با جداسازی سخت `executive_private`؛ استودیو و مقصدها ابتدا با adapter آزمایشی و کنترل‌های مستقل خروجی. هیچ ارسال واقعی یا هزینهٔ AI بدون مجوز.
6. **B09:** جایگزینی API نمایشی با API احراز هویت‌شده، سپس داشبوردهای نقش‌دار و میز خبر واقعی. پنهان‌کردن دکمه در UI کنترل امنیتی محسوب نمی‌شود.
7. **پیش از VPS:** آزمون‌های قرارداد، مرز دسترسی، مهاجرت/بازگشت، صف و idempotency، و بازبینی Gate-00 و حقوق انتشار. اطلاعات شبکه، secret store، CMS و مقصدهای رسمی هنوز تصمیم و دسترسی واقعی می‌خواهند.

در `docs/CODE_TARGETS.csv` هر ردیفِ `implement` از `manifests/tasks.csv` آمده است: ۱۴۶ هدف، که در تصویر لحظه‌ای بالا ۱۴ مسیر در `main` وجود دارد و ۱۳۲ مسیر وجود ندارد. این جدول برنامهٔ ساخت است، نه گزارش تکمیل.
