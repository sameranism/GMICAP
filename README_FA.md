# ETEMAD / Cursor Prompt Pack — نسخه ۲.۰

**نوع خروجی:** فقط **پرامپت‌، قوانین و برنامه توسعه**؛ این بسته محصول اجرایی کامل یا کد تولید خبر نیست.

- 223 پرامپت مستقل هدفمند برای 223 مسیر فایل یکتا.
- ۱۱ مرحله (S00 تا S10) و ۱۱ پرامپت بازبینی Gate.
- ۹ بسته B01..B09؛ پوشش هر ۲۹ پروژه P01..P29.
- ۳۰ قرارداد JSON Schema همراه با نمونه داده و ۱۰ سند Word اصلی + متن Markdown قابل خواندن در Cursor.
- به‌ازای هر تسک، فایل `__ATTACHMENTS.txt` کنار پرامپت.
- ماتریس CSV مسیر فایل، مدل، قرارداد، تسک و مرحله.

## دقیقاً چه فایلی را همراه هر پرامپت بفرستی؟

فایل `__ATTACHMENTS.txt` کنار **همان** `PROMPT.md` تمام مسیرهای لازم را دارد؛ این منابع در `source/` همراه بسته موجودند. وقتی مخزن به Cursor Cloud وصل باشد، نیازی به پیوست تکراری DOCX نیست: فایل‌های Markdown و JSON را با `@path` در متن اشاره کن. اگر منبع در مخزن وجود ندارد، پیش از شروع فقط همان فایل موردنیاز را ارسال کن.

## نکته کلیدی اسناد

اسناد نسخه ۱.۱ هنوز برای B09 به `Mantine` اشاره می‌کنند. تصمیم جدید کارفرما **shadcn/ui + Tailwind v4** است؛ تعارض را با `ADR-002` در S00 حل کن، نه با بازنویسی پنهانی سند اصلی. SQLهای اولیه نمونه طرح‌اند و ابتدا باید به مهاجرت‌های بازبینی‌شده تبدیل شوند.

## خطرات باز

CMS واقعی، لوگو/رنگ رسمی روزنامه، تأیید رسمی API برخی مقصدها و بررسی حقوقی نشر ایران هنوز تکمیل نشده‌اند. Agent نباید برای این‌ها نتیجه ساختگی ارائه کند. APIهای واقعی و انتشار پیش از مجوز باید خاموش باشند.
